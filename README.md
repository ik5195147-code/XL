# SoundX
Kotlin, zero third-party dependencies (plain Android Views). minSdk 26, target 33.
Build: GitHub Actions (.github/workflows/build.yml) or `./termux-build.sh`. APK: app/build/outputs/apk/debug/app-debug.apk
Install, then: Settings → Floating Button ON (grant overlay) → Root tab → Check Root → Routing Test → Dump mixer.
